Mode d’emploi

Le parcours se joue dans votre terminal.

Cette page est la seule documentation dont vous avez besoin. Vous la lisez, vous recopiez les commandes, et tout le reste se passe hors-ligne, chez vous. Aucun compte, aucune installation, aucun droit d’administration.

  1. 1. Téléchargez l’archive

    Un seul fichier, 250 Ko, qui contient les 45 niveaux et le lanceur.

    Télécharger airgap42-labs.tar.gz

  2. 2. Vérifiez son empreinte

    Avant d’extraire quoi que ce soit, comparez. C’est la leçon du module 3 appliquée à nous-mêmes : ne faites confiance à aucun fichier dont vous n’avez pas vérifié l’origine, y compris le nôtre.

    sha256sum airgap42-labs.tar.gz

    La sortie doit être exactement :

    …

    Sur macOS, la commande est shasum -a 256 airgap42-labs.tar.gz. Si l’empreinte diffère, n’extrayez pas l’archive et écrivez-nous.

  3. 3. Extrayez et lancez

    tar xzf airgap42-labs.tar.gz
cd airgap42-labs
./airgap42

    Le lanceur vous dit où vous en êtes et quel niveau vous attend.

  4. 4. Enregistrez votre clé, si vous en avez une

    Les trois premiers niveaux sont ouverts à tous. Pour la suite, collez la clé reçue après votre achat :

    ./airgap42 licence AG42-XXX-XXXXX-XXXXX-XXXXX

  5. 5. Jouez

    ./airgap42 niveau 1      # lire le briefing
./airgap42 valider 1     # répondre aux questions de contrôle
./airgap42 progression   # où j'en suis

    Un niveau validé ouvre le suivant. Une leçon par jour, 45 niveaux, six semaines.

Pourquoi le terminal

Un cours sur l’isolation ne peut pas vivre dans un navigateur.

Hors-ligne pour de bon

Le lanceur ne contacte aucun serveur et n’écrit que dans son dossier. Débranchez votre machine : le parcours continue de fonctionner. C’est la meilleure façon de le suivre.

Lisible avant d’être exécuté

Le lanceur tient en un seul fichier shell. Ouvrez-le, lisez-le, puis lancez-le. Un cours qui vous demanderait d’exécuter un programme sans le lire se contredirait.

Rien à installer

Ni paquet, ni conteneur, ni droits d’administration. Seulement sh et openssl, déjà présents sur Linux et macOS. Sous Windows : WSL ou Git Bash.

Ce que le lanceur fait exactement

  • Il lit les fichiers de son propre dossier et les déchiffre avec votre clé.
  • Il écrit votre progression dans un sous-dossier .etat.
  • Il n’ouvre aucune connexion réseau, ne lit rien ailleurs sur votre disque, ne demande aucun privilège.

Le contenu des niveaux est chiffré en AES-256-CBC avec une dérivation PBKDF2, au format natif d’OpenSSL. Votre clé de licence ouvre une enveloppe qui contient la clé du niveau. Une licence Pro ouvre aussi les niveaux Essentiel.

Les trois premiers niveaux sont gratuits.

Téléchargez, vérifiez, jouez. Vous déciderez ensuite.
