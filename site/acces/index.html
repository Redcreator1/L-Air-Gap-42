Votre clé de licence.

Il n’y a rien à activer sur ce site. Votre clé s’enregistre dans le lanceur, sur votre machine, et elle y reste.

1. Où est ma clé ?

Elle vous a été affichée juste après le paiement et envoyée par e-mail. Format : AG42-XXX-XXXXX-XXXXX-XXXXX. Les lettres O et I n’y figurent jamais, pour éviter les confusions avec les chiffres 0 et 1.

2. Enregistrez-la dans le lanceur

Dans le dossier extrait de l’archive :

./airgap42 licence AG42-XXX-XXXXX-XXXXX-XXXXX

Le lanceur vérifie la clé en ouvrant un niveau, puis vous confirme le palier déverrouillé. Vous pouvez l’enregistrer sur autant de vos machines que vous voulez.

3. Pas encore de clé ?

Les trois premiers niveaux sont ouverts à tous, sans clé : voir le mode d’emploi. Pour la suite, choisissez votre palier.
